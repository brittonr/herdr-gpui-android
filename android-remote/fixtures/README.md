# Synthetic generation-1 SSH fixture

This is a loopback-only protocol fixture, not a Herdr daemon. It runs no shell,
process, terminal, user session, real host connection, or daemon lifecycle command.
It accepts only the exact probe and bridge command strings generated by
`herdr-client` for session `android-test`; the strings are compared, never run.
Wire encoding and endpoint types come directly from `herdr-protocol`.

Run `cargo run --manifest-path android-remote/fixtures/Cargo.toml --locked`.
The single startup JSON line contains the bound loopback port, ephemeral public
host-key fingerprint, and explicitly public test login. Stop with Ctrl-C; only
this process's listener and accepted sessions are closed. The screen starts
with `SYNTHETIC SSH FIXTURE` so screenshots cannot be mistaken for a real daemon.

Host adapter integration tests:
`cargo test --manifest-path android-remote/fixtures/Cargo.toml --locked`.

For emulator testing, use the returned port and fingerprint with host `10.0.2.2`
inside the Android VM. Keep the fixture and emulator in the same execution
session when the environment isolates networking between tool calls. A fixed
port may be selected with `-- --port 22222`. The private host key exists only in
memory; the printed username/password are public test constants.

The pane ID is `w1:p1`. Each accepted focus response is correlated to its request
ID, followed by a newer matching snapshot and surface. Text is shown as
`Text: …`; keys are shown as `Key: Enter modifiers=0 Press` (and the corresponding
shared protocol key variant). The fixture records semantic event batches, and
its 80×16 surface retains the last 13 input lines below the synthetic banner.
It echoes endpoint health pings and does not implement terminal emulation.

Limits: eight connections, four SSH session channels per connection, the shared
2 MiB inbound frame limit, 64 KiB per recorded input batch, 64 recent records,
and a two-second shutdown deadline. Malformed input closes its own connection.
Tests cover the production adapter over TCP SSH, Unicode and ordered batches,
focus gating, no replay on reopen, wrong host pins, strict command rejection,
fragmented framed input, oversize frame rejection, and cancellation during an
unfinished SSH handshake. These prove synthetic protocol interoperability;
compatibility with a real Herdr deployment remains a separate check.
The library also exposes `Scenario::StallBridge` for deterministic cancellation
checks: SSH accepts the exact bridge exec, but withholds protocol readiness.
The adapter test verifies immediate handle invalidation and closure of the
underlying accepted TCP connection without sending hello or semantic input.

Fixture diagnostics are JSON on stderr, capped at 256 records per process.
They report a connection counter, elapsed milliseconds, TCP acceptance, SSH
banner acceptance/failure, and the final SSH session outcome. Error details
are selected typed categories and numeric protocol/OS fields. They never log
credentials, keys, commands, payloads, remote free-text errors, or terminal input.
Startup connection metadata remains the first stdout line.
